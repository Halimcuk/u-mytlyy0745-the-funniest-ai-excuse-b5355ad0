A one-line excuse from an AI agent that failed a task — it went to the documentation for help, and the documentation asked it for help first. The program writes that single line to `entry.txt`.

> I asked the docs for help. They asked me for help first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The entry line is 56 characters long, and the output is deterministic: every run writes the exact same line.
